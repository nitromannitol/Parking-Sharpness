*Sharpness and critical scaling of parking*, Bou-Rabee and Panagiotis,
arXiv:2609.02820.  This file records what a machine has checked, and how
to check it again.  It is generated by `python3 tools/certificate.py`; do
not edit it by hand.

## What is claimed

The paper's registered statements are proved in Lean 4 from Mathlib and the
shared library `LatticeProb`, under the hypotheses displayed in their frozen
declarations, with no added axiom and no `sorry`, for every node in state
`SEALED` or `PROVED` below.  Cited inputs are proposition-valued predicates in
`Parking/External/`, carried as explicit hypotheses together with each
theorem's own hypotheses; 12 of the 13 are proved inside this
repository and are marked accordingly.  `CORRESPONDENCE.md` records the correspondence with
the paper and `PROOF.md` describes the proof and the Lean tree.

## Reproducing it

```
elan toolchain install $(cat lean-toolchain)
lake build Parking
python3 tools/check_manifest.py     # frozen statements match their hashes
python3 tools/check_axioms.py       # sorryAx appears only where the state says so
python3 tools/check_warnings.py     # the build emits no unauthorized warning
python3 tools/check_constants.py    # parameter order for uniform constants
python3 tools/sync_docs.py --write  # generate the manifest-derived tables
python3 tools/certificate.py --check
```
